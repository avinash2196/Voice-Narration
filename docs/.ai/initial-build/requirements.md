## Acceptance Criteria
(Each acceptance criterion maps to one or more P0 requirements above; tests are to be specified in M1/M2 as required.)

- AC-ACCT-001 (Account isolation): Given two separate User accounts, A and B, when A attempts to list or access B's voice profiles, samples, or narration jobs, the system denies access (403) and no audio content is exposed. [Verifies R-ACCT-002, R-ACCT-003]

- AC-CONS-001 (Consent recording): When a user enrolls a voice profile, the system records a consent event containing account id, timestamp, consent text/version, and consenting identity; the consent record is immutable and queryable by administrators for auditing. [Verifies R-CONS-001]

- AC-ENR-001 (Enrollment): Enrollments accept only validated audio formats and explicit model-aware upload input, applying approved model/configuration duration bounds before sample acceptance. Enrollment completes only if the actual six-part quality checks pass or the user explicitly overrides the current overrideable assessment after informed warning. The approved Q11 policy, deterministic measurement evidence and human calibration acceptance gates apply before dependent enablement. No mocked final findings, missing metrics or unavailable evaluator may manufacture a pass. Resulting profile metadata includes model/version, sample references, consent reference and enrollment status; profile/model listing obeys supplied pagination and existing catalog order. Samples reused for another profile model are independently revalidated against that model. [Verifies FR-010, FR-011, FR-012, FR-013; User: Q11; User: Q12]

- AC-GEN-001 (Generation core workflow): An authenticated User selects an authorized voice profile, submits a script and idempotency key, receives a job id, and the job progresses through queued→running→completed (or failed). On completion, a preview URL and download link (signed, authorized) are available to the submitting user only. Retries with same idempotency key do not create duplicate final audio artifacts. [Verifies R-WORK-001, FR-022, FR-045, FR-024]

- AC-HIST-001 (History and audit): Each user has a queryable history listing past narrations with immutable metadata (profile id, model version, params, timestamps) and authorized access limited to the owner and permitted admins. Q13 known-cost facts may update only the permitted operational measured-cost field of retained history; after content purge, legitimate accounting facts do not recreate a Job and public retrieval remains unavailable. [Verifies R-ACCT-003, FR-023, FR-045; User: Q13]

- AC-RET-001 (Deletion and revocation): When a user deletes a profile or revokes consent, original samples, derived embeddings, and generated audio associated with the profile are removed from primary object storage and model stores within a bounded window (configurable, default 24 hours). Audit metadata (account id, deletion timestamp, operator id) is retained per admin-configured retention. The system must reject all future generation requests using the deleted profile. Q13 preserves only the specified content-free accounting facts for the account lifetime, permits narrowly authorised incurred-cost reconciliation, and keeps purged retrieval unavailable; it restores no voice content, grant or execution permission. [Verifies R-REV-001, R-DEL-001, R-RET-001, FR-045; User: Q13]

- AC-SEC-001 (Secrets and data protection): Secrets are stored in managed secret storage; object storage enforces signed downloads; all data in transit and at rest is encrypted; access follows least privilege. [Verifies FR-046]

- AC-QUOTA-001 (Quotas and budget enforcement): Per-user quotas, rate limits and concurrency caps are enforced at submission time; administrative controls produce alerts when forecasted monthly spend exceeds $20 target; an operator-configurable kill switch prevents execution when configured spend thresholds are reached. Q13 governs boundary-crossing jobs, default/override window changes and content purge: quantities project original admission/request facts, active concurrency includes all unfinished jobs, money holds survive month rollover and unknown terminal cost, and one known settlement recognises cost once in its first durable Policy-receipt month. Views distinguish quantity and budget periods. Unknown cost stays null; fresh-ID reconciliation and identical replay never double-release or double-charge; conflicting final cost/duration remains a conflict. Missing complete accounting facts fail closed rather than count as zero. [Verifies R-GEN-001, FR-044, FR-045, NFR-008, R-RET-001, R-DEL-001; User: Q13]

- AC-LIC-001 (Licensing gate): Before enabling any model for production use, a model evaluation artifact exists documenting exact source URL, license/weights permissions, and explicit approval by an Administrator; system prevents enabling models without such approval. [Verifies R-LIC-001]

- AC-EXP-001 (Expressive controls): The UI exposes pause strength and speech pace controls within tested safe ranges; when used, generated audio reflects the adjusted pause and pace without breaking voice identity. Controls are available only when the selected model supports them and pass model-feasibility validation in M1; advanced emotion controls remain P1 until validated. [Verifies basic expressive controls P0]
