## Evaluator mechanism and dependency boundary

Use NumPy and PyAV for decoding, sample counting, normalized arrays, frame power and statistics. Their presence suffices for these arithmetic features; it does not supply a validated speech classifier. [PyAV's official audio documentation](https://pyav.org/docs/stable/api/audio.html) describes audio frames, NumPy conversion and resampling. Its stable documentation currently identifies an older documentation version; exact behavior on the pinned av 19.0.2 runtime must be verified in the later prerequisite/implementation evidence, not assumed from that documentation.

Recommend WebRTC's classical GMM VAD rather than a new neural model. The [official implementation](https://webrtc.googlesource.com/src/+/refs/heads/main/common_audio/vad/vad_core.c) compares speech and noise hypotheses using frequency-band features and embedded statistical parameters. The [official API](https://webrtc.googlesource.com/src/+/refs/heads/main/common_audio/vad/include/webrtc_vad.h) supports framed PCM, modes 0–3 and reports a speech/no-speech decision; higher aggressiveness increases missed detections. Proposed mode 1 balances screening against over-warning, subject to calibration. This is not transcription, speaker verification, consent verification or proof that speech belongs to the enrolling person.

The [upstream license](https://webrtc.googlesource.com/src/+/refs/heads/main/LICENSE) permits redistribution with conditions. Source headers also reference PATENTS and AUTHORS. This evidence supports investigation, not a claim that an arbitrary Python wheel or full transitive distribution is cleared.

## Proposed deterministic measurement policy v1

Decode actual permitted audio bytes, not filename/container duration metadata. Existing byte/count/format limits and active-owner-consent checks apply before persistence/use. Count decoded sample frames at each stream rate for duration. Select the container-designated default audio stream; if several defaults or none exist, select the lowest-index decodable audio stream. Use that same selection consistently for metadata, assessment, playback and conditioning; record its index privately. Multiple streams are not a new rejection condition. Channels within the selected stream remain supported. This deterministic selection rule is proposed for contract review.

Normalize decoded PCM to floating full-scale units using its sample-format scale; do not peak-normalize, denoise, trim silence, compress or alter the stored original. Nonfinite decoded values are corrupt/invalid audio. Compute clipping on every original channel before resampling. For analysis, resample each channel separately to 16 kHz using the pinned PyAV path, retaining channels to avoid antiphase downmix cancellation. Process nonoverlapping 20 ms (320-sample) frames. Weight the final partial frame by real sample count in aggregate energy/silence; zero-pad it for VAD input only, and count only its real duration. Quantize VAD PCM by round-half-even of `32768*x`, saturating to [-32768,32767]. A fresh VAD instance per channel/sample starts in mode 1; no added smoothing or hangover beyond the pinned upstream detector.

For each analysis frame, power is mean squared normalized samples, RMS is its square root, and dBFS is `10*log10(power)`. Zero power has no finite dBFS and is handled explicitly, never serialized as infinity/NaN. Use IEEE float64 for signal arithmetic, integer counts for ratios/duration where possible; compare unrounded measurements, then serialize finite decimal values half-even to six places per the contract. Repeatability tolerance for the exact pinned decoder/resampler and threshold-edge fixtures belongs in the reviewed RED plan.

| Finding | Measurement, aggregation and proposed warning rule | Feedback |
| --- | --- | --- |
| duration | Seconds from decoded samples. Every sample must be within the selected model's explicitly approved Capability.sample_min_seconds/sample_max_seconds, inclusive, and any stricter explicitly configured bounds. For an assessed profile report the shortest sample's seconds; all samples are checked. No universal 3/5/10/30-second model limit is invented here. | Record/upload within the displayed effective duration bounds. |
| clipping | Per sample/channel fraction of original decoded values with absolute magnitude >= 0.999. Profile measurement is maximum fraction across samples/channels; warning if > 0.001 (0.1%). This detects near-full-scale samples, not all analog distortion. | Lower microphone gain and re-record; encoded overshoot may also trigger this indicator. |
| silence | For each sample, a frame is quiet only if every channel's RMS is <= -50 dBFS. Fraction is quiet real duration / decoded duration. Report maximum sample fraction; warning if > 0.60. This is low-energy duration, not a linguistic pause detector. | Reduce long quiet sections or move closer to the microphone. |
| noise | Estimated SNR per sample/channel using VAD groups: S=mean power over speech-labelled real samples, N=mean power over non-speech-labelled real samples, estimated SNR=`10*log10((S-N)/N)`. Requires >= 0.30s labelled speech, >= 0.30s labelled nonspeech, N>0 and S>N. Report minimum valid estimate across samples/channels that have labelled speech. Warning if <15 dB, or any required sample has no valid estimate. No finite estimate for zero N, no reference separation or insufficient groups: measured=null, unit=dB, explain uncertainty. | Seek a quieter room; if inconclusive, include a brief natural pause and re-record or acknowledge the uncertainty. |
| level | Per sample/channel RMS over VAD speech-labelled real samples. Report minimum finite dBFS among channels with labelled speech; warning if any such level <-35 dBFS or >-10 dBFS. If both low and high channels occur, minimum is reported and message explains both; if a sample has no speech-labelled finite level, measured=null and warn. | Adjust microphone distance/gain; re-record rather than silently boosting the sample. |
| speech_presence | A frame is speech-labelled when any channel VAD reports speech. Per sample labelled speech duration / total decoded duration; report minimum fraction across samples; warning if <0.20 or speech-labelled duration <1.00s for any sample. measured is fraction, unit=ratio; message states short detected duration when relevant. | Speak naturally in Hindi or English; music/noise and quiet speech can confuse detection. Re-record or acknowledge the warning. |

Pass means the defined measurement meets its screening bounds, not “good voice identity” or “guaranteed speech.” All required samples are checked independently; pooling never lets a clean long sample conceal an unsuitable short sample. Missing/inconclusive metrics produce warning with measured=null, never fabricated zero or a pass. Measurements remain owned by the assessment; public response still has exactly six findings. A failed decode/upload admission has no completed Quality assessment and therefore need not fabricate six measurements.

The estimated SNR assumes non-speech frames represent background noise and additive noise is reasonably comparable across the clip. Music, intermittent noise, detector mistakes and continuous speech violate this approximation. [NIST's official SNR discussion](https://www.nist.gov/itl/iad/mltg/nist-speech-signal-noise-ratio-measurements) uses an explicit statistical estimation method; it does not validate the simpler estimator proposed here. This proposal uses the transparent VAD-group estimate as a warning indicator and calibrates it against known mixtures; it does not call it true isolated-source SNR or invoke NIST software.

## Warning, failure and override behavior

Preserve the contract's pending → quality_checking → enrolling → enrolled path and its awaiting_user_override warning branch. Acoustic clipping/silence/noise/level/speech-presence issues, including zero-energy audio within otherwise valid duration/format bounds, are **overrideable warnings**, not newly invented hard rejections. Any warning leads to awaiting_user_override, override_allowed=true and override_acknowledged=false. All pass leads to enrolling with both override flags false. Acknowledging the current assessment permits conditioning/enrollment; it does not guarantee model success or bypass the selected-model gate.

Format, corruption, bytes/count, hard duration and active consent/ownership rules remain nonoverrideable. Upload admission uses the approved 400 behavior; later hard/execution failures use failed with actionable Failure and no override. Lost/revoked consent fences work immediately. VAD/runtime execution failure is a dependency/execution failure, not a low-confidence warning that can bypass unavailable required checks. Missing policy/calibration/evaluator readiness prevents the dependent operation with 503 CONFIGURATION_REQUIRED or DEPENDENCY_UNAVAILABLE as appropriate; no hidden fallback or auto-pass.

Preserve PATCH /voices/{profile_id}/quality-override with exact {assessment_id,acknowledged:true}, current assessment requirement, existing 409 errors and semantic-repeat behavior. Re-recording creates new authorized artifacts/assessment; it cannot revive a stale acknowledgement. Pin the effective policy configuration revision, evaluator artifact identity and calibration reference privately with each assessment. A configuration change does not rewrite historical findings or duplicate enrollment. Unfinished assessments using an obsolete policy must be reassessed under the new revision before accepting an override; prior assessment IDs become stale. This reassessment rule is a proposed clarification for contract review. Hard consent/resource safety always uses live state.

Persist only the existing sample references and necessary measurement/provenance metadata. Do not log sample bytes, transcripts, embeddings, filenames or private listening annotations. Recheck active authorization at sample access and before publishing/conditioning; existing deletion/retention fences remain authoritative.

## Calibration and verification before enablement

Recommended acceptance numbers below also require human approval. Calibration ownership: **avinash2196**, acting as human Administrator, owns authorizing a private consented validation set and appointing a Hindi-capable and English-capable reviewer (one qualified person may cover both). No voice collection or reviewer outreach is requested or performed now. Missing consented examples, reviewer assignment or approval means calibration is Waiting and enrollment enablement stays disabled, rather than manufacturing evidence from generated tones.

1. Freeze policy/evaluator/decoder versions, exact settings, hashes and a private dataset manifest. Split tuning and held-out sets by speaker/source before threshold tuning. Do not reuse held-out cases to tune and still call them held out. Record each attempt, uncertainty and limitation; failing calibration requires a revised human-reviewed policy.
2. Deterministic synthetic fixtures cover PCM extremes, exact threshold equality and just-above/below, zeros, gain-scaled waveforms, known quiet spans, stereo/antiphase channels, frame tails, resample rates, WAV/MP3/M4A decode and mismatched/corrupt bytes. Verify computed duration, near-peak counts, low-energy fraction and power against independent analytic expectations (ratio/duration tolerance <=0.000001 after six-place serialization). Encoded-lossy examples compare decoded ground truth, not pre-encode amplitude assumptions. Synthetic tones/noise are negative speech examples, never positive speech ground truth.
3. Use separately authorized natural Hindi/English recordings and non-speech controls. Reviewers annotate speech intervals and sample suitability independently of displayed evaluator outputs; disagreements are adjudicated before scoring. Include quiet voices, unvoiced consonants, natural pauses, background fans/traffic/music, clipping, low/high levels and codec/channel variation. No claim of children/accents/device coverage beyond represented consented data.
4. Proposed minimum held-out screen: 40 suitable speech clips per language and 40 non-speech clips, from >=5 independent sources per language/control group. Report speech-missed rate (speech clip fails speech-presence rule), false-speech rate (non-speech clip passes it), and usable-clip warning rate by language and condition. Candidate acceptance: <=10% speech-missed in each language; <=10% false-speech controls; <=15% otherwise suitable clips receive any non-duration acoustic warning in each language. Report exact denominators and 95% Wilson intervals; these small-set observed rates are not population guarantees. No acceptance based solely on pooled Hindi+English scores.
5. For estimated SNR, mix authorized clean speech with independently known noise at 5/15/25 dB true mixture SNR, across at least two noise types and each language. Proposed gate: median absolute estimation error <=5 dB among estimable cases, >=80% estimable coverage, and >=80% warning recall at5dB / <=15% false warnings at25dB, reported separately by language. Show null/negative-estimate cases and boundary15dB behavior; do not exclude them to improve coverage. If infeasible, revise estimator/unknown semantics through review rather than quietly accept a meaningless “noise check.”
6. Human adjudication verifies that each acoustic warning/action is understandable and recoverable. Contract tests verify all six findings, raw measurements rather than mocked final decisions, warning acknowledgement/stale IDs/repeats, no conditioning before permitted transition, actual HTTP errors, live consent fences and safe evaluator-failure behavior. Existing persistence and authentication/consent suites remain regression constraints; no tests run for this documentation draft.

Deterministic fixture correctness can be demonstrated during Enrollment RED/GREEN without a production model. Human calibration evidence must be collected through a later expressly authorized execution and approved before enabling the policy. Model identity/listening scores remain the separate selected-model evaluation gate; passing these acoustic checks cannot satisfy it.
